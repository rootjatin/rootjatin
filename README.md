## 👨‍💻 About Me

I am a **Control Systems Developer at NCRA, India**, working at the intersection of control engineering, robotics, embedded systems, and Linux.

I enjoy building systems where software directly interacts with the physical world—from reading sensors and processing telemetry to running control loops and commanding actuators.

My work and interests include:

* Designing and tuning control systems
* Developing embedded firmware for sensors and actuators
* Integrating hardware and software into complete working platforms
* Building telemetry, monitoring, and debugging tools
* Working with Linux-based development environments
* Exploring robotics, astronomy, space technology, and cybersecurity

## 🤖 Featured Project

### Gyani 2.0 — Humanoid Robotics Platform

<img src="./gyani.gif" width="210" align="right" alt="Gyani 2.0 humanoid robot">

**Gyani 2.0** is a humanoid robotics platform focused on control systems, embedded firmware, and end-to-end hardware–software integration.

The project brings together sensing, control, telemetry, debugging, and actuation into one complete robotic system.

### Key areas

* Control-loop design and system tuning
* Embedded firmware for sensors and actuators
* Real-time sensing, processing, and actuation
* Telemetry and debugging tools
* Hardware–software integration
* Reliability testing and iterative improvement
* Complete sensing → control → actuation pipeline
