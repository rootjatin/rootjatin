## 🤖 Featured Project

### Humanoid Robot — **Gyani 2.0**

<p>
  <img src="gyani.gif" width="170" align="right" alt="Gyani 2.0 Humanoid Robot"/>
</p>

**Gyani 2.0** is a humanoid robotics platform focused on control systems, embedded firmware, and end-to-end hardware–software integration.

Key areas of work include:

- Designing and tuning control loops for stable behaviour
- Developing embedded firmware for sensors and actuators
- Handling real-time sensing, control, and actuation
- Building telemetry and debugging tools
- Improving system reliability through continuous testing and iteration
- Integrating the complete pipeline from sensing to control to actuation
