## 🤖 Featured Project

### Humanoid Robot — Gyani 2.0

<img src="./gyani.gif" width="170" align="right" alt="Gyani 2.0 humanoid robot">

**Gyani 2.0** is a humanoid robotics platform focused on control systems, embedded firmware, and end-to-end hardware–software integration.

* Control-loop design and system tuning
* Embedded firmware for sensors and actuators
* Real-time sensing, control, and actuation
* Telemetry and debugging tools
* System testing and reliability improvements
* Complete sensing → control → actuation integration
